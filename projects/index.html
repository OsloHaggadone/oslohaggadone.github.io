  • Synopsist

    Music platform · In progress

    My music streaming platform: my 34 songs stream for free in a player I built, installable as an iPhone app and used by 35+ listeners. It records how people listen, to find the moments in each song they replay.

    • A player in vanilla JavaScript with offline downloads, playlists, an EQ, and visuals that follow each song’s analysis
    • Anonymous play, pause, seek, and skip events go to a serverless Cloudflare Workers API and D1 (SQLite), with validation and rate limiting: 6,150+ logged
    • A Python and Essentia pipeline embeds every 4-second moment (Discogs-EffNet) and finds similar ones by nearest-neighbor search; matching a song’s other versions rose from 10% (chance) to 96%
    • JavaScript
    • Python
    • Cloudflare Workers
    • SQLite
    • Essentia

  • SplitSlice

    Command-line app · 2026

    A pizza-ordering assistant for Domino’s, in the terminal. Describe an order in plain English (“2 lg pep and a couple sprites”) and change it the same way.

    • Four agents (orchestrator, retrieval, preference, fulfillment) run the conversation, keep the cart, learn preferences, and price the order
    • Gemini turns each message into structured JSON, with a keyword parser when it’s unavailable
    • Budget modes give up what you care about least, preferences are learned from order history, and the bill splits to the cent
    • Prices orders with Domino’s but never places them
    • Python
    • Gemini API
    • SQLite
    • pizzapi
